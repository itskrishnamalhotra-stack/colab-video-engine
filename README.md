# Illustrated WebGL video runtime

[Open the reusable GPU notebook](https://colab.research.google.com/github/itskrishnamalhotra-stack/colab-video-engine/blob/main/GPU_Runtime.ipynb).

Select an NVIDIA GPU and run the cell. It prepares Node, Chrome and FFmpeg,
then displays a temporary bridge URL and private token. Keep the token private;
it grants command, terminal and file access to this runtime. No Drive mount is
required. No video is rendered during setup.

The production style is permanently the existing illustrated round-headed
cartoon family. Improve its wardrobe, expressions, accessories, directional views,
props and staging within that family. The abandoned Blender pipeline and its
character assets are retired. Previous launchers are absent from current main;
old commits remain historical records.

The bridge accepts prepared projects repeatedly. It supports portrait and
landscape output, measured animation-contact sound, live progress, finalization
of completed capture segments, and verified downloads. NVIDIA rendering is
checked when capture starts; software graphics fallback is rejected.

Use one persistent browser on the measured two-core T4 by default. One through
eight workers are selectable per job, but additional workers can be slower.
Runtime lifetime and free GPU availability are controlled by the provider.

See [runtime and source notes](RUNTIME.md). This public distribution contains
the runtime and reusable source modules, not private projects, voices/models,
reference footage, cloud credentials or publishing account data.
